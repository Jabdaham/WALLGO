현재 진행

사각말을 순서대로 배치합니다. 이미 말이 있는 칸에는 놓을 수 없습니다.

    온라인 대전

    별도 Firebase 설정이나 로그인이 필요 없습니다. 이 페이지가 Firebase에 자동으로 연결하고 익명 인증을 처리합니다.

    현재: 로컬 2인 모드

    온라인 접속은 Firebase Realtime Database를 사용합니다. 공개 서비스로 운영하기 전에는 데이터베이스 보안 규칙과 방별 접근 권한을 강화해야 합니다.

    규칙 요약

    사각말은 상하좌우 1~2칸, 원형말은 주변 8칸으로 이동합니다. 원형말의 대각선 이동은 L자 경로의 벽과 중간 칸을 확인합니다. 이동 후 말 주변의 빈 변 하나에 벽을 설치합니다. 한 턴의 제한시간은 90초이며, 사각말 배치가 끝난 뒤 말 선택·이동·벽 설치 전체에 적용됩니다. 시간이 끝나면 현재 선택한 말(없으면 자기 말 중 하나) 주변의 설치 가능한 벽 중 하나가 균등한 확률로 자동 선택됩니다. 모든 영역에서 양쪽 플레이어의 말이 더 이상 공존하지 않으면 종료합니다. 말이 있는 영역의 칸만 해당 플레이어 점수에 합산합니다.

    시제품 v0.4 · 턴 제한시간 90초 · 영역 칸 수는 연결된 말의 소유자를 기준으로 계산합니다. 빈 영역은 점수에 포함하지 않습니다.
